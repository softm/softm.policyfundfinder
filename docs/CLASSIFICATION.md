# 지원한눈 자동 지원방식 분류 및 품질 개선

- 기준일: 2026-10-16
- 수집: 네이버 공개 JSON 전체 목록 + 개별 상세, 기업마당 공식 API(키 설정 필요)
- 분류: 원천 분야(category)는 유지, 지원 유형(type)·목적(purpose)·네이버 중분류(subcategory)만 참고용 규칙 분류
- 증거 순서: 제목의 구체적 지원방식 > 원천 지원방식 코드 > 원천 태그 > 상세 본문 > 원천 분야 > 미확인
- 보조금 + 대출 복합 공고는 한쪽으로 추측해 확정하지 않고 '복합지원', 융자 + 이차보전이 제목에 함께 있으면 '금융지원'
- 교육·행사와 지원금이 혼재하면 제목상 프로그램 제공을 우선하며, 상세에 분류 근거를 표시
- 기존 수집본에도 동기화 시 동일 분류를 적용. 장기간 지난 자료는 원문 확인 필요
- 지원사업 종류 필터: 지원금, 정책융자, 이자지원, 바우처, 서비스·현물, 금융지원, 복합지원, 지원사업(미확인)
- 주요 상태 지표: totalCount, detailCount, npayMissingDetailCount, npayActiveMissingDetailCount, typeCounts
- 페이지 배포: CI 테스트 전체 통과 → 정적 파일 인덱스 + 상세 gzip 파일 무결성 검증 → 배포
- 기업마당 키: secrets.BIZINFO_API_KEY가 없으면 이전 성공본 유지(수집 성공으로 오인하지 않도록 상태 표시)

## 주의·후속 과제

규칙에 의한 지원유형 분류는 법적 자격판정, 지급확정 또는 자동 원문 대조가 아니다. 실제 지원금액/조건·중복지원 여부는 공식 공고를 반드시 확인한다. 잔여 과제: 원문 각 필드와의 정합성 모니터링, 복합지원의 멀티라벨 필터(복합지원 검색뿐 아니라 각 재정지원 검색에도 동시에 노출), 지역·업종 신청자격 정밀 파싱과 원문 버전관리.
