# 지원한눈 공유 기능

## 사용 방법

| 위치 | 기능 |
| --- | --- |
| PC·모바일 상단의 앱 공유 | 검색조건을 제외한 공개 서비스 첫 화면 공유 |
| 공고 카드의 공유 아이콘 | 공고 상세로 연결되는 링크 공유 |
| 공고 상세 하단의 공유 | 상세 안내를 유지한 채 독립 공유창 열기 |
| 조회 조건의 검색조건 공유 | 지역·유형·목적·분야·세부분야·검색어·태그·접수상태 공유 |
| 공유창의 앱으로 공유 | 지원 브라우저에서 운영체제 공유 대상 선택 |
| 링크 복사 / 내용 + 링크 복사 | URL 또는 제목·기관·지원내용·접수기간과 URL 복사 |

네이티브 공유에 표시되는 앱은 운영체제·브라우저·설치 앱에 따라 달라집니다. 카카오 JavaScript SDK를 사용하는 전용 카카오톡 템플릿 공유는 이번 구현에 포함하지 않습니다. 앱 공유가 없는 환경에는 복사 버튼을 제공합니다. 자동 복사가 차단되면 읽기 전용 URL을 선택해 직접 복사할 수 있습니다.

## 링크 및 개인정보

공고는 공개 운영 주소의 `?notice=<ID>`로 연결합니다. 기존 데이터 초기화·중복 통합 ID 별칭·상세 복원 경로를 그대로 사용합니다. 검색 링크는 허용된 공개 검색 매개변수만 직렬화합니다. 프로필, 매출, 사업 별명, 관심목록, 준비 체크리스트, 메모, 추적·인증 매개변수는 자동으로 포함하지 않습니다. 사용자가 검색창에 직접 입력한 검색어는 검색조건 공유에 포함됩니다.

검색조건 공유에는 개인 맞춤 조건과 정렬이 포함되지 않습니다. 받는 사람은 최근 공고순으로 보며, 데이터 갱신에 따라 결과 건수는 달라질 수 있습니다. 해당 사실은 공유창에도 표시합니다.

## 구현 구조

- `public/sharing.js`: 공개 URL 허용목록, 공유 문구, Web Share API, 복사 폴백.
- `public/sharing-ui.js`: 독립 `share-dialog`, 접근성·포커스·스크롤 복원, 공유 버튼 연결.
- `public/sharing.css`: 데스크톱·모바일 공유창 스타일.
- 루트 `index.html`에서 독립 ES 모듈을 불러오므로 기존 Pages 빌드와 루트 공개 경로 모두 대응합니다. `public/index.html`의 이전 주소 리디렉션은 유지합니다.
- 기존 화면이 문자열로 다시 그려지는 구조이므로 앱 루트와 상세창만 관찰하여 공유 버튼을 중복 없이 연결합니다. 기존 상세 공유 이벤트를 캡처 단계에서 처리해 레거시 복사 실패 안내가 상세창을 덮어쓰지 않게 합니다. 기존 검색·태그·문서 뷰어 상태는 수정하지 않습니다.
- 공유 취소 시 자동 복사하지 않습니다. 처리 중 중복 실행을 막고, 닫은 뒤 도착하는 비동기 결과는 무시합니다. 외부 공유 SDK나 외부 단축 URL 서비스에 데이터를 보내지 않습니다.
- 서비스 워커 캐시는 `policyfundfinder-pages-v6-share`이며 공유 모듈·스타일을 자산 목록에 추가했습니다.

## 검증

```sh
node --test tests/sharing.test.mjs
node --test --test-concurrency=1 tests/core.test.mjs tests/catalog.test.mjs tests/pages.test.mjs tests/sharing.test.mjs
node scripts/build-pages.mjs
```

공유 단위 테스트 18개를 추가했고 Pages CI에도 포함했습니다. 배포 직전 로컬 테스트는 18개 모두 통과했습니다.

기존 배포 아티팩트의 실제 앱 코드와 전체 정적 공고 자료를 사용한 오프라인 Chromium 렌더링에서 데스크톱 9개·모바일 7개 시나리오를 통과했습니다. 이 검증의 URL/history, Worker 전송, 운영체제 공유·클립보드 인터페이스는 테스트 대역을 사용했습니다. 실제 Android/iOS 기기에서 카카오톡·문자 앱까지 전송한 실기기 검증은 수행하지 않았습니다.

검증 범위: 카드 버튼 중복 방지, 제목·링크 복사, 상세창 유지, Escape·포커스·스크롤 복원, 복사 차단 수동 안내, 한글 필터 공유, 공고 ID 초기 진입, 네이티브 공유 취소·권한 오류, 중복 클릭·지연 완료, 320/375/390/768px 공유창 가로 넘침, 브라우저 오류 확인.
