# 지원한눈

사업 조건으로 정책자금과 지원사업을 검색하고 비교·신청 준비를 관리하는 한국어 모바일 웹앱.

## 현재 기능

- 기업마당 공식 API 전체 제공 피드 수집. 16건 제한 없음. 전체 건수 불일치·페이지 반복·수집 실패 시 이전 성공 자료 유지.
- 서버 D1에 공고·수집 이력 저장, 검색 및 12건씩 결과 페이지. 이전 공고는 관심사업용 마지막 수집본 보관.
- 공식 인증키 검증 후 서버 AES-GCM 암호화 보관. 브라우저와 백업에 키를 저장하지 않음.
- 마지막 성공 시각·건수·수집 중·실패·36시간 이상 지연 표시.
- 인증키가 미연결되거나 최초 수집이 없을 때만 초기 공식 공고 16건(2026-10-12 원문 확인)을 명확하게 표시.
- 브라우저 프로필 10개, 관심 저장, 비교 3개·CSV, 체크리스트·메모·신청 상태, 마감일 ICS, 대출·자부담 계산, 백업·복원, PWA.

API 수집 자료의 지역·분야는 검색 분류다. 금액·기업 규모·소재지 제한·세부 자격은 자동으로 추정하지 않는다. 기업마당이 제공하지 않는 기관별 공고·전체 역사자료·실시간 예산 잔여는 보장하지 않는다.

## 운영

앱의 **공고 데이터 연결**에서 https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi 에서 발급받은 키를 연결한다. 서버 비밀 환경변수 `BIZINFO_KEY_ENCRYPTION_SECRET`을 먼저 설정해야 한다. `BIZINFO_API_KEY` 비밀 환경변수도 지원한다. 키를 로그·소스·프롬프트에 넣지 않는다.

수집/조회·재시도·클라우드 작업 연결은 [OPERATIONS.md](OPERATIONS.md)를 따른다. 예약 갱신은 실제 인증키/업스트림 접근/서비스 쓰기를 검증한 후 설정한다. 인증키 없이 전체 자료가 수집되거나 자동 갱신이 작동한다고 표시하지 않는다. Site는 소유자 비공개이며 공유 쓰기 경로는 플랫폼 접근 제어를 사용한다. 외부 공유 전 추가 관리자 인증을 구현해야 한다.

프로필·관심·준비 기록은 브라우저 저장이다. 전체 공고의 조건 비교 검색은 필요한 프로필 조건만 요청 중 처리하며 서버에 저장하거나 애플리케이션 로그로 남기지 않는다.

## 구조와 검증

Vinext/Cloudflare Worker (`build/sites-worker.ts`) + D1, 기존 Vanilla JS UI (`public/`). `app/route.ts`가 `frontend.html`을 제공한다. 스키마 `db/schema.ts`와 생성된 `drizzle/` 마이그레이션은 배포 시 적용한다.

`npm test`: 필터·한국 날짜·조건·상환·캘린더 및 417건 테스트 응답 수집, 페이지 완결성, 암호화, 실제 SQLite를 통한 원자적 교체·검색·실패 보존을 검증한다. 테스트 응답은 배포 자료로 저장하지 않는다.

의존성 설치/빌드/패키징은 Sites 제공 스크립트 사용. 관리형 런타임에 control-browser가 없어 브라우저 QA는 미검증이다. 기능 테스트·빌드·배포 및 API 응답을 확인한다.

## 공고 분야·상세·첨부파일

공식 대분류와 실제 응답의 `pldirSportRealmMlsfcCodeNm` 중분류로 검색한다. 지역·기간·지원유형·키워드와 조합하며, 필터를 선택하기 전 후보 집합의 분야별 건수를 표시한다. 공식 분류 누락은 `기타`와 구분하여 `분류 미제공`으로 표시한다. 검색 링크에 분야·중분류·접수 상태를 보존한다.

상세에는 사업개요 원문 텍스트, 소관기관과 수행기관, 공식 신청 URL 및 기업마당 공고 URL을 각각 표시한다. 지원 안내의 두 번째 `☞` 이후 문장을 출처 텍스트로 표시하며 수치형 지원한도를 임의 추정하지 않는다. API 공고문·첨부서류의 이름과 URL을 저장한다. PDF는 레이어 미리보기와 공식 원본 링크를 제공하고 HWP/HWPX는 공식 파일 링크로 연결한다. API가 반환하지 않은 추가 첨부는 원문에서 확인한다.

`확정 접수 기간 내`, `접수 예정`, `접수 기간 미확인`을 구분한다. 앱의 건수는 기업마당 API 현재 수집본의 건수이며 전국 모든 기관 또는 전체 과거 공고의 누적 건수가 아니다. 타 서비스와 비교할 때 제공처·진행중 필터·기간·집계시각을 함께 확인한다.

## 통합 전체 수집과 뷰어

네이버 공개 검색의 전체 공고 목록을 페이지 끝까지 수집해 보관한다. 원천 전체 건수·진행중 건수·고유 공고 ID 수를 검증하고, 제목과 마감일이 일치하는 공고를 통합한다. 기업마당 정보가 있으면 공식 분류·본문·신청 URL·첨부파일을 우선한다. 원천 건수와 중복 제거 검색 건수는 따로 표시한다. 목록 데이터는 D1 SQL로 검색·필터·페이지 처리해 대량 자료를 Worker 메모리에 전부 읽지 않는다. 추가 공고의 상세는 열 때 읽고 저장한다.

공식 PDF를 R2에 검증·저장해 제공처 연결 장애 중에도 미리보기를 제공한다. 브라우저는 PDF 응답만 뷰어에 넣고 오류 JSON/HTML은 별도 안내로 표시한다. 팝업을 닫거나 다른 화면으로 이동하면 요청을 취소하고 PDF Blob URL을 해제한다.
